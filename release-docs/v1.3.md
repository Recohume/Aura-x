# Aura v1.3

Release Tags: [release, v1.3, android, kotlin, jetpack-compose, fcm, inner-tube, supabase, ota-updates, shared-element-transition, media3]

---

## Overview

Aura v1.3 is a major release featuring a Yomite-inspired autonomous OTA update engine, Firebase Cloud Messaging (FCM) push notification pooling via Supabase, crisp 544px square retina artwork processing across YouTube Music InnerTube streams, a redesigned lyrics shared-element morphing transition with natural text tracking, gesture-driven mini-player track switching, smooth audio fade-out dynamics, and full playlist & artist collection exploration with play metrics.

---

## What's Changed

- **Lyrics Shared Element Transition**:
  - Implemented container bounds morphing and corner radius animation without anisotropic scale squashing (`scaleX = 1f`, `scaleY = 1f`), preserving 100% natural font size and line height.
  - Dynamically hides the bottom player controls section as soon as the full-screen lyrics screen shrinks back toward the card slot (`showPlayerControls = isLyricsExpanded && lyricsExpansionProgress >= 0.90f`).
  - Seamless card docking crossfade below `0.35f` progress to align preview text with the resting card slot.

- **Interactive Floating Mini-Player Gestures**:
  - Dedicated middle text viewport with strict clipping (`clipToBounds()`), preventing sliding title/artist text from overlapping cover art or playback controls.
  - Dynamic track pull animation: sliding left pulls the next song from the right, sliding right pulls the previous song from the left.
  - Dual-gesture pointer input: tapping title/artist expands the full-screen player, while dragging triggers horizontal track swiping with spring physics.

- **Audio Engine Dynamics (Fade-Out & Shuffle Logic)**:
  - Added smooth 200ms audio fade-out (`pauseWithFadeOut()`) on pause and fade-in (`playWithFadeIn()`) on play to eliminate abrupt audio cuts.
  - Integrated a 2-second proportional audio fade-out during track completion.
  - Fixed autoplay behavior on search results to strictly honor shuffle toggle configuration.

- **Search & Collection Exploration**:
  - Search result song tiles now play immediately when tapping either the title/artist section or the cover art.
  - Eliminated initial frame flickering when navigating between search results and other navigation tabs.
  - Universal collection parser for Albums (`MPREb_...`), Singles, EPs, and Playlists (`VL...`, `PL...`) with total views/plays (e.g. `386.1M total plays`) and per-track play counts (e.g. `84M plays`).
  - Cleaned playlist view count display: removed the pill background, border, and EQ icon in favor of clean lime typography.

- **Autonomous OTA Update Experience & Settings**:
  - In-app full-screen release modal with markdown changelog rendering, live download progress, and direct APK installation via `FileProvider`.
  - Settings screen diagnostic hub cleanup: removed preview buttons and extraneous labels, standardizing to `AURA Music v1.3`.

- **High-Resolution Artwork & Real-Time Notifications**:
  - Replaced low-resolution thumbnails with 544x544 retina square album art (`=w544-h544-l90-rj`) and 720p HD video thumbnails.
  - Integrated Firebase Cloud Messaging (FCM) topic subscriptions and Supabase device pooling for instantaneous update announcements.
