# Aura v1.4

Release Tags: [release, v1.4, android, kotlin, jetpack-compose, exo-player, merging-media-source, playlists, video-mode, scoped-storage, brand-identity]

---

## Overview

Aura v1.4 is a landmark release introducing complete custom playlist creation with gallery cover art selection, dynamic Spotify playlist import toggling, universal "Add to Playlist" sheet modals across all screens, adaptive 1080p/720p high-definition video multiplexing via ExoPlayer `MergingMediaSource`, zero-loss artwork preservation for Spotify tracks in video mode, context-aware offline download management, and an official brand identity overhaul renaming the app strictly to **"Aura"** featuring the custom Obsidian Cyber Bunny mascot.

---

## What's Changed

### 🎨 Brand Identity & System Modernization
- **Official App Name Rebrand**: Renamed from "AURA Music" to **"Aura"** across the entire application stack, including Android manifests, settings screen, launcher identifiers, update modals, and system notifications.
- **Obsidian Cyber Bunny Mascot**: Introduced our official IP mascot—an obsidian cyber bunny with glowing lime optics and studio headphones—symbolizing speed, precision, and immersive audio depth.
- **Adaptive Vector Launcher Icons**: Fully redesigned launcher icons across all screen densities (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`, `ic_launcher_round`, `ic_launcher_foreground`), replacing blurry legacy rasters with crisp vector graphics.
- **Fluid Launch Splash**: Integrated `AuraLaunchSplash` vector launch splash screen featuring smooth entry animations and seamless handoff into the main application shell.
- **README & Brand Assets**: Updated repository documentation and asset pipelines with official typography, color tokens, and visual identity.

### 📁 Custom Playlist Creation & Fluid Library Management
- **Interactive Header Action**: Replaced the static three-dot icon in the Library header with an interactive `+` action button.
- **Create or Import Modal (`AuraCreateOrImportModal`)**: Quick-action bottom sheet modal offering immediate choices: "Create a playlist" or "Import Playlist from Spotify".
- **Custom Playlist Creation Modal (`AuraCreatePlaylistModal`)**:
  - Direct gallery photo picking via Android Photo Picker (`rememberLauncherForActivityResult(GetContent)`).
  - Custom playlist title and description input with live validation.
  - High-contrast neon-lime primary action button.
  - Automated navigation to the "Playlists" pill tab (`activeTab = 1`) upon creation with an informative toast notification.
- **Dynamic `+` to `X` Spotify Import Morph**:
  - Selecting "Import Playlist from Spotify" curtains down the modal and expands the inline Spotify import card above the library filter pills.
  - Dynamically transforms the header `+` icon into an `X` (`Icons.Rounded.Close`).
  - Tapping `X` collapses the Spotify import card and restores the `+` creation button.

### 🎵 Universal "Add to Playlist" & Multi-Screen Ergonomics
- **Universal Add to Playlist Sheet (`AuraAddToPlaylistModal`)**:
  - Reusable bottom sheet displaying track preview (artwork, title, artist).
  - Quick "+ New Playlist" action button at the top of the playlist list.
  - Displays all user playlists with track counts and checkmark / add status indicators.
- **Universal Integration**: Wired "Add to playlist" option into 3-dot bottom sheet modals across all screens (`LibraryScreen`, `SearchScreen`, `PlaylistDetailsScreen`, and `AuraNowPlayingSheet`).
- **Playlist Management Modal (`AuraPlaylistOptionsModal`)**: Added options to play next, add to queue, edit, or delete playlists.
- **Long-Press Gestures**: Holding any song tile or playlist tile across the app now triggers its respective 3-dot bottom sheet modal for ergonomic one-handed use.
- **Tile UI De-cluttering**: Removed redundant play button overlays from playlist cards and tiles.
- **Actionable Toasts**: Added immediate feedback toast notifications for playlist deletion and song removal.
- **Navigation Routing Fix**: Fixed back-arrow navigation from playlist details to reliably return to the Playlists pill tab instead of resetting to "All".

### 🎬 High-Definition Video Mode & Spotify Integration Architecture
- **Adaptive 1080p/720p Video Extraction**: Refactored `SimpMusicExtractorEngine.kt` to extract adaptive 1080p and 720p video streams paired with high-bitrate Opus (160kbps) / AAC (128kbps) audio streams.
- **Multiplexed ExoPlayer Playback**: Integrated `MergingMediaSource` in `AuraPlayerManager.kt` to multiplex separate HD video and audio streams seamlessly without quality throttling or 360p caps.
- **Spotify Artwork Preservation**: Resolved issue where Spotify imported songs lost album art or had cover art overwritten by low-resolution YouTube thumbnails when switching between video and audio modes. Original `originalAudioTrack.highResArtworkUrl` is strictly preserved for background ambient blur and mini-player states.
- **Zero-Loss Mode Switching**: `AuraPlayerManager.switchToAudioMode()` and `playVideoForTrack()` preserve playback position, original queue, and active index, preventing playback restarts or queue wiping.
- **Graceful Music Video Fallback**: Fixed songs without official music videos from displaying black screens or misleading "(HD VIDEO)" tags. The player intelligently verifies stream availability and falls back cleanly.
- **Clean Thumbnails**: Removed misleading "LIVE" pills from YouTube search thumbnail overlays.

### 💾 Scoped Storage & Offline Audio Management
- **Scoped Storage Architecture**: Enhanced `AuraStorageRepository.kt` with scoped storage permission handling (`READ_MEDIA_AUDIO` / `WRITE_EXTERNAL_STORAGE`) with proactive user permission requests.
- **Live Download Progress**: Integrated real-time download progress tracking via `_downloadProgress` state flows in `AuraViewModel`.
- **Dynamic Track Options**: Songs currently in the "Downloaded" category dynamically change option from "Download" to "Remove from downloads".
- **Offline Synchronization**: Preserved synchronized timestamped lyrics and dominant color palette extraction persistence for offline playback.

### ⚡ UI/UX Polish & Fluid Interfaces
- **Maximized Video Full-Player Presentation**: Seamless video playback viewport surrounded by dynamic real-time ambient blur sampled from the original album art.
- **Fluid Interface Standards**: Strict adherence to fluid micro-interactions: 44dp minimum touch targets, `:focus-visible` compliance, GPU-composited animations, and true unicode ellipsis `…`.

## Technical Specifications

- **Version Name**: 1.4
- **Version Code**: 4
- **Application ID**: `com.auramusic.kotlin`
- **Audio & Video Engine**: AndroidX Media3 (ExoPlayer 1.5.1) with `MergingMediaSource` (Adaptive 1080p/720p Video + 160kbps Opus Audio)
- **UI Framework**: Jetpack Compose (BOM 2024.12.01) with Material 3 & Fluid Interfaces
- **Extractor Engine**: SimpMusic PipePipeExtractor + NewPipeExtractor + OkHttp
- **Notifications**: Firebase Messaging 33.7.0 (BoM)
- **Database**: Supabase PostgREST (PostgreSQL)
- **Minimum SDK**: API 26 (Android 8.0)
- **Target SDK**: API 36 (Android 15+)
- **Storage**: Android Scoped Storage (`MediaStore` & App External Files)
