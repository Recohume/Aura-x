# Aura v1.4.4

Release Tags: [release, v1.4.4, android, kotlin, jetpack-compose, in-app-update, keystore, notifications, ui-polish]

---

## Overview

Aura v1.4.4 establishes a permanent release signing keystore to eliminate `App not installed as package conflicts with an existing package` errors during direct in-app updates, introduces a custom monochrome vector mascot for Android system notification icons, and refines notification layout ergonomics so update alerts stay compact and elegant.

---

## What's Changed

### 🔐 Permanent Release Signing Keystore
- **Eliminated Signature Mismatch Conflict**:
  - Previously, GitHub Actions generated an ephemeral release keystore on each virtual machine run, resulting in differing cryptographic certificates between successive APK releases.
  - Committed the permanent production keystore (`keystore/release.keystore`) directly into the repository and configured both Gradle `signingConfigs` and the GitHub Actions packaging step to sign every release with the identical key.
  - Resolves `App not installed as package conflicts with an existing package` (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`), ensuring seamless, frictionless in-app updates across all future releases.
  - *Note for upgrade*: Because previous interim builds were signed with ephemeral keys, install this permanent release fresh once. All subsequent updates will install seamlessly without conflicts.

### 🐰 Monochrome Mascot Notification Silhouette
- **Custom Mascot System Icon**:
  - Replaced the round launcher mask with a dedicated monochrome vector silhouette of the Aura Obsidian Cyber Bunny wearing headphones (`ic_aura_notification.xml`).
  - Correctly fills the notification badge circle and the Android status bar with the iconic bunny silhouette.
  - Added Firebase Cloud Messaging metadata for default notification icon and AURA Neon Lime branding color (`@color/aura_neon_lime`).

### 📱 Notification Drawer Layout Ergonomics
- **Non-Expanding Compact Card**:
  - Retained the high-resolution, full-color mascot thumbnail on the right side of the notification card using `setLargeIcon`.
  - Removed full-bleed `BigPicture` expansion so notifications stay clean, compact, and readable when the notification dropdown is expanded or tapped.
