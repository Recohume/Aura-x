# Aura v1.4.3

Release Tags: [release, v1.4.3, android, kotlin, jetpack-compose, in-app-update, bugfix, ui-polish, search-engine]

---

## Overview

Aura v1.4.3 delivers focused UI refinements and search engine enhancements across the app. This release eliminates circular outline badges on the mascot logo in favor of a flatter and enlarged footprint, deduplicates version headings in release changelogs, re-indexes official music video discovery queries, adorns push notifications with the app mascot, streamlines full-screen player options, and revamps the playlist creation sheet with modern borderless aesthetics.

---

## What's Changed

### 🎨 Flat Mascot Logo & Changelog Deduplication
- **Flat Obsidian Bunny Mascot**:
  - Removed circular container outline and dark circular badge from the in-app update modal hero header.
  - Replaced raster background asset with the transparent `R.drawable.aura_bunny_mascot`, rendered cleanly without corner clips.
  - Enlarged the mascot display footprint to 112dp for maximum visual presence.
- **Release Changelog Header Deduplication**:
  - Suppressed redundant `# Aura`, `# Version`, and plaintext version titles inside `MarkdownChangelogView`.
  - The sheet header's prominent `Version v1.4.3` now serves as the sole authoritative title beneath "WHAT'S NEW".

### 🎬 Accurate Official Music Video Query Re-Indexing
- **Enhanced Search Query Structure**:
  - Updated query formulation in `SimpMusicExtractorEngine.findOfficialMusicVideo` to `(song name) + artist + Music Video Official` (`"$titleForQuery $artistForQuery Music Video Official"`).
  - Ensures YouTube and YouTube Music algorithms prioritize authentic official music videos and MVs rather than topic audios, fan lyric videos, or acoustic covers.

### 🔔 Android Push Notification Mascot Icon
- **Large Icon Mascot Branding**:
  - Configured `AuraNotificationManager` to decode and attach `R.drawable.aura_bunny_mascot` as the large icon for system update notifications via `NotificationCompat.Builder.setLargeIcon`.
  - Provides instant brand recognition in the Android notification drawer and status shade.

### 🎛️ Full-Screen Player 3-Dot Options Cleanup
- **Streamlined Modal Menu**:
  - Removed "Upcoming Queue" and "Lyrics View" from `NowPlayingOptionsModal` in `AuraNowPlayingSheet`.
  - Dedicates the 3-dot sheet to high-value playback actions (switching video/audio mode, downloads, live performances, theme switching, artist navigation, and playlist management).

### ⚙️ Settings Screen Refinement
- **Audio Stream Quality Row**:
  - Removed the redundant "Lossless" pill text badge from the "Audio Stream Quality" row in `SettingsScreen` for a cleaner, unified settings aesthetic.

### 📁 Create Playlist Sheet Redesign
- **Horizontal Split Layout & Borderless Text Fields**:
  - Replaced stacked vertical layout with an ergonomic horizontal `Row`: 110x110dp cover picker on the left, stacked Title and Description fields on the right.
  - Eliminated all border widths and outline strokes from text input fields in favor of subtle, borderless containers (`focusedIndicatorColor = Color.Transparent`, `unfocusedIndicatorColor = Color.Transparent`).

### 🔍 Search Screen Artist Result Cleanup
- **Simplified Artist Header**:
  - Removed the "Follow" pill button from `ArtistSearchResultHeader` in `SearchScreen`, keeping the verified artist avatar, display name, and subscriber count clean and unobstructed.
