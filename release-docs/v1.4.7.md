# Aura v1.4.7

Release Tags: [release, v1.4.7, android, kotlin, jetpack-compose, in-app-update, playlist-controls, home-options, ui-polish]

---

## Overview

Aura v1.4.7 establishes exact circular APK icon branding in the in-app update experience and system notifications, refines playlist and album action controls with borderless icons and dynamic Shuffle/Repeat swap, and replaces redundant circular play buttons on Home screen song tiles with standardized 3-dot options.

---

## What's Changed

### 🎨 Exact Circled APK Icon Branding
- **Pre-Rendered Anti-Aliased Circular Asset**:
  - Generated `R.drawable.aura_app_icon_round` directly from `assets/icon.png` matching the official Android APK launcher round icon with transparent corner masking.
  - In `AuraUpdateModal`, replaced the cutout transparent mascot with `R.drawable.aura_app_icon_round` inside the 104.dp circular badge.
  - In `AuraNotificationManager`, notification thumbnails (`setLargeIcon`) now load `R.drawable.aura_app_icon_round` for clean, consistent circular presentation.

### 🎛️ Borderless Playlist & Album Action Controls (`PlaylistDetailScreen`)
- **Eliminated Gray Circle Fills & Borders**:
  - Removed gray circular backgrounds (`0xFF1E2028`), border widths, and border colors from the Heart and Shuffle action buttons.
  - **Heart / Like Button**: Displays a clean borderless `FavoriteBorder` in white when unsaved; fills with vibrant `AuraNeonLime` (`Favorite`) when saved to the user's Library.
  - **Dynamic Shuffle & Repeat All Swap**: Displays borderless `Shuffle` in white when inactive. When tapped, it starts playback and seamlessly swaps to `Repeat All` (`Icons.Rounded.Repeat`) in `AuraNeonLime`! Tapping again reverts to Shuffle.
  - Retained the prominent neon lime circular "Play All" button.

### 🎵 Home Screen Category Song Tiles (`SpotifyTrackRowItem`)
- **Standardized 3-Dot Options Button**:
  - Removed redundant circular play buttons on song tiles in "New Release", "Trending", "Top Chart", etc., as tapping the row itself already initiates playback.
  - Added the standardized 3-dot options icon (`Icons.Rounded.MoreVert`) on each song tile.
  - Tapping opens `AuraTrackOptionsModal`, giving instant access to:
    1. **Play Next**
    2. **Add to Queue**
    3. **Add to Liked Songs**
    4. **Add to Playlist** (opens `AuraAddToPlaylistModal`)
    5. **Go to Artist**
