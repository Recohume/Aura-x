# Aura v1.4.1

Release Tags: [release, v1.4.1, android, kotlin, jetpack-compose, in-app-update, bugfix, stability]

---

## Overview

Aura v1.4.1 is a targeted stability release resolving a critical crash during direct in-app update installation, eliminating negative corner computation exceptions during download progress animations, and streamlining the release changelog modal layout.

---

## What's Changed

### 🛠️ In-App Update Engine Stability
- **Resolved Negative Corner Size Crash**:
  - Fixed `java.lang.IllegalArgumentException: Corner size in Px can't be negative` in Jetpack Compose when initiating in-app APK downloads.
  - Replaced the spring animation on download progress fill with a monotonic `LinearOutSlowInEasing` tween transition (`durationMillis = 200`), eliminating negative values from spring undershoot.
  - Clamped animated progress strictly to `[0f, 1f]` before assigning to layout width.
  - Removed redundant nested `clip(RoundedCornerShape(percent = 50))` from the inner fill layer since the outer container already enforces the capsule boundary.
  - Prevented zero-width layout rendering (`clampedProgress > 0.001f`).

### 🎨 Changelog UI Polish
- **Cleaned Up Release Notes Formatting**:
  - Removed redundant hardcoded title header under "WHAT'S NEW" in `AuraUpdateModal` to eliminate stacked duplicate version titles.
  - The markdown changelog now renders cleanly as the sole authoritative title.
