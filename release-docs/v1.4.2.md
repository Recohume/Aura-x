# Aura v1.4.2

Release Tags: [release, v1.4.2, android, kotlin, jetpack-compose, in-app-update, bugfix, stability, ui-polish]

---

## Overview

Aura v1.4.2 is a targeted bugfix and stability update addressing crashes in the direct in-app update downloader, eliminating negative corner calculation and format string parsing exceptions, reducing background update cadence for rapid release discovery, and refining the update modal header layout with a flatter, high-contrast mascot presentation.

---

## What's Changed

### In-App Update Engine Stability & Crash Fixes
- **Resolved String Format Crash During APK Download**:
  - Fixed `java.util.IllegalFormatFlagsException: Flags ='('` during download progress updates caused by unescaped `% (` in format strings (`Downloading $percent% (%.1f / %.1f MB)`).
  - Pre-formatted numerical values independently using US locale string interpolation, making download progress updates 100% crash-proof.
- **Resolved Negative Corner Size Crash**:
  - Fixed `java.lang.IllegalArgumentException: Corner size in Px can't be negative` in Jetpack Compose when initiating in-app APK downloads.
  - Replaced the spring animation on download progress fill with a monotonic `LinearOutSlowInEasing` tween transition (`durationMillis = 200`), eliminating negative values from spring undershoot.
  - Clamped animated progress strictly to `[0f, 1f]` before assigning to layout width.
  - Removed redundant nested `clip(RoundedCornerShape(percent = 50))` from the inner fill layer since the outer container already enforces the capsule boundary.
  - Prevented zero-width layout rendering (`clampedProgress > 0.001f`).
- **Cadence Optimization**: Reduced update check throttling cadence from 12 hours to 15 minutes in `AuraUpdateManager` to ensure instant discovery of new releases.

### Changelog & Mascot UI Polish
- **Flat Mascot Presentation**: Removed the circular container box and border outline from the update modal hero header, rendering the Obsidian Cyber Bunny mascot flatter and enlarged to 96dp for high contrast.
- **Eliminated Duplicate Version Header**:
  - Removed redundant hardcoded title header under "WHAT'S NEW" in `AuraUpdateModal`.
  - Filtered out redundant `# Aura` and `# Version` markdown headers from `MarkdownChangelogView` since `Version v1.4.2` is already prominently displayed at the top of the modal sheet.
