# Aura v1.4.5

Release Tags: [release, v1.4.5, android, kotlin, jetpack-compose, in-app-update, notifications, search-filter, playlist-header]

---

## Overview

Aura v1.4.5 fixes the "PLAYING FROM" full-screen player header to display authentic playlist names instead of song durations, refines push notification presentation with a circular mascot thumbnail and direct in-app update navigation, and corrects the Search screen "Playlists" filter to exclusively return playlists.

---

## What's Changed

### 🎵 Playlist Title Header in Full-Screen Player
- **Eliminated Duration Clutter in Header**:
  - Filtered out raw duration timestamps (e.g. `4:19`) and view counts from being assigned as album/source names in InnerTube list item parsers.
  - Properly stamps the playlist title (`album = playlist.name`) when playing tracks from imported Spotify playlists, user created playlists, and community curated collections.
  - Added safety filtering in `AuraNowPlayingSheet` so duration-like strings are never presented in the "PLAYING FROM" top bar.

### 🔔 Push Notification Mascot & Direct Update Navigation
- **High-Priority Data-Only FCM Delivery**:
  - Converted the GitHub Actions FCM release notifier payload into a high-priority data message. This prevents Google Play Services from overriding notifications with generic music notes and guarantees local execution in `AuraFirebaseMessagingService`.
- **Circular Mascot Thumbnail**:
  - Programmatically masks the Aura mascot into a crisp circular 192x192 bitmap thumbnail set as `setLargeIcon` on the right side of the notification.
  - Employs `NotificationCompat.BigTextStyle` to keep the layout compact and non-expanding on pull-down.
  - Uses the monochrome headphone-wearing bunny silhouette for the small notification circle badge.
- **Direct Update Screen Deep-Link**:
  - Configured `com.auramusic.app.OPEN_UPDATE` intent action with `PendingIntent`. Tapping the update notification directly launches Aura, bypasses the splash screen, and immediately triggers the `AuraUpdateModal` update dialog.

### 🔍 Search "Playlists" Pill Filter
- **Exclusive Playlist Results**:
  - Resolved parameter encoding for YouTube Music community playlist queries (`fetchCommunityPlaylists`).
  - Added dedicated `searchPlaylistResults` state flow in `AuraViewModel`.
  - When the "Playlists" filter pill is selected, only matching community and user playlists are returned in a dedicated list tile format; individual songs and the "Featuring" artist carousel are cleanly suppressed.
