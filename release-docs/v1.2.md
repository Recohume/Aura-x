# Aura v1.2

Release Tags: [release, v1.2, android, kotlin, jetpack-compose, media3, innertube, production, universal-apk]

---

## Overview

Aura v1.2 marks the first production-grade universal release of the standalone native Android client, engineered from the ground up in 100% modern Kotlin and Jetpack Compose. This release integrates official AURA visual branding, dynamic runtime package versioning, automated CI/CD release gate enforcement, and an audio pipeline powered by AndroidX Media3 and YouTube Music InnerTube.

---

## What's Changed

- Brand Identity: Integrated official AURA adaptive launcher icons across all screen densities (MDPI to XXXHDPI) with dark obsidian `#0A0B0E` background canvas.
- Settings Screen Overhaul: Replaced hardcoded version text with dynamic Android `PackageManager` package inspection, presenting the exact runtime version name and monotonically increasing build code.
- Official Logo Badge: Replaced generic equalizer placeholder in Settings with the official high-resolution AURA brand mark.
- Automated Release Documentation Gate: GitHub Actions workflow strictly mandates the presence of `release-docs/v<version>.md` for any release build.
- Upgraded Toolchain: Configured complete compilation and target toolchain for OpenJDK 21 LTS, Gradle 8.12.0, and Kotlin 2.1.20.

---

## Key Features

### 1. High-Fidelity Audio & Streaming Engine
- Direct Opus and AAC audio stream playback at bitrates up to 256kbps.
- AndroidX Media3 ExoPlayer integration with foreground `MediaSessionService`.
- System lock screen media notification with interactive playback scrubbers, play/pause, next, and previous triggers.
- Hardware audio session routing with active wake lock management.

### 2. Synchronized Lyrics Engine
- Dual-mode lyrics presentation: inline 3-line synced preview on player card and full-screen karaoke overlay.
- Powered by LRCLIB API with automatic fallback to YouTube Music synced or plain transcripts.
- Real-time millisecond-accurate auto-scrolling with user interactive scroll override.
- Optional Romanization toggle for Asian scripts (Japanese, Korean, Chinese).

### 3. Integrated Equalizer & SponsorBlock
- 10-Band equalizer preset engine with hardware curve bypass and 7 tuned profiles: Flat, Bass Boost, Treble Boost, Vocal, Acoustic, Rock, and Electronic.
- SponsorBlock integration for automated detection and silent skipping of sponsor segments, intros, and non-music interludes.

### 4. Search & Caching Infrastructure
- Real-time search suggestions and instant query execution across tracks, artists, albums, and playlists.
- Dual-tier media caching: disk cache for offline playback and in-memory cache for ultra-fast track loading.

## Bug Fixes & Refinements

- Resolved static version label bug: version name and code now dynamically reflect `packageInfo.versionName` and `packageInfo.longVersionCode`.
- Added missing `@color/iconBackground` resource in `res/values/colors.xml` to prevent adaptive icon build warnings on API 26+.
- Streamlined settings screen layout to eliminate redundant container boxes for a clean, borderless design.
- Hardened APK signing pipeline using `zipalign -p 4` followed by v1/v2/v3 signature generation via `apksigner`.

## Technical Specifications

- Programming Language: Kotlin 2.1.20
- Runtime & Compiler: OpenJDK 21 LTS (Temurin)
- UI Framework: Jetpack Compose (BOM 2025.02.00)
- Audio Core: AndroidX Media3 (ExoPlayer 1.5.1)
- HTTP & Serialization: Ktor 3.0.3, KotlinX Serialization 1.7.3
- Min Android SDK: API 26 (Android 8.0 Oreo)
- Target Android SDK: API 36 (Android 15+)
- Architecture: MVVM + Repository Pattern + Clean Architecture
