# Aura v1.4.6

Release Tags: [release, v1.4.6, android, kotlin, jetpack-compose, in-app-update, playlist-like, playlist-options, notifications]

---

## Overview

Aura v1.4.6 brings circled app icon branding to Android push notifications and the in-app update experience, ensures high-contrast black typography on the update downloading pill, and introduces comprehensive playlist liking, saving, and 3-dot options across Search results and Playlist Details.

---

## What's Changed

### 🎨 Circled App Icon in Notifications & Update Screen
- **Anti-Aliased Circular Notification Thumbnail**:
  - Notification `setLargeIcon` now renders `assets/icon.png` (`R.drawable.aura_logo`) into a smooth anti-aliased circle using `PorterDuff.Mode.SRC_IN`.
  - Replaces the transparent cutout silhouette with the official dark-canvas icon, ensuring uniform circular branding on Android notification drawers.
- **Circled Icon in App Update Hero Header**:
  - Updated `AuraUpdateModal` hero header to display the official `assets/icon.png` clipped into a 104.dp circular badge (`CircleShape`) with `ContentScale.Crop`.

### ⚡ High-Contrast Black Downloading Text on Update Modal
- **Pill Container Visual Polish**:
  - The downloading progress pill now uses a clean light base background (`LightButtonBg`) with smooth neon lime (`AuraLime`) progress fill.
  - The progress label (`"Downloading X% (X.X / X.X MB)"`) is rendered in bold black typography (`Color.Black`), ensuring permanent, crystal-clear readability and WCAG AAA contrast ratio throughout the entire download duration.

### 💖 Playlist Liking, Saving & 3-Dot Options
- **Search Playlist Results (`SearchResultPlaylistTile`)**:
  - Added dedicated Heart / Like button and 3-Dot Options button to each playlist result tile in the Search screen.
  - Tapping the Heart icon instantly toggles saving the playlist to the user's personal Library (`playlists`).
  - Added `AuraCommunityPlaylistOptionsModal` bottom sheet when tapping the 3-dot button, providing quick actions:
    1. **Save to Library / Remove from Library** (with dynamic filled/outline heart icon)
    2. **Play Playlist** (immediately begins playback of the community playlist)
    3. **View Playlist Details** (opens full tracklist screen)
    4. **Share Playlist** (shares native YouTube Music link via Android Share Sheet)
- **Playlist Detail Screen (`PlaylistDetailScreen`)**:
  - Added a circular Like / Save Playlist Heart button in the top action header alongside "Shuffle" and "Play All".
  - Tapping the button saves the full playlist and all its loaded tracks to the user's Library, persisting across app restarts.
- **Asynchronous Track Hydration**:
  - Saving a community playlist from search automatically triggers background track hydration to fetch all tracks, ensuring offline tracklists populate cleanly.
